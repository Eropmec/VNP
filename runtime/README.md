# Рантайм (Godot 4.4+)

Интерпретатор формата проекта v1: читает папку проекта и проигрывает игру.
Одна и та же программа работает как игра, как превью внутри редактора и в автотестах.

```
main.gd               точка входа: аргументы, интерфейс, связь с редактором
vn/project_data.gd    чтение проекта и индексы
vn/expr.gd            условия и эффекты (зеркало editor/vnformat/expr.py)
vn/game_state.gd      переменные, посещения, случайность; снимок для сохранений
vn/story_runner.gd    обход графа и команд сцены; ничего не рисует, только сигналы
vn/stage.gd           фон, персонажи, переходы, музыка и звуки
vn/asset_loader.gd    ассеты по ID: из упакованной игры или прямо с диска
vn/editor_link.gd     JSON-RPC с редактором
ui/                   диалоговое окно и меню выбора
tests/run_tests.gd    46 проверок ядра без окна
game/                 упакованный проект (сейчас — «Старый дом»), кладёт tools/pack_game.py
```

## Запустить игру в Godot

1. Запусти Godot, в менеджере проектов нажми **Импорт** и выбери `runtime/project.godot`.
2. Первый раз Godot импортирует картинки и звуки, это несколько секунд.
3. Нажми **F5** (или ▶ вверху справа). Играет `runtime/game`.

Управление: клик / пробел / Enter — дальше (первый клик дописывает текст), **Esc** — меню,
**F5 / F9** — быстрое сохранение / загрузка, **F11** — во весь экран. При запуске из редактора ещё:
**F3** — отладка с переменными, **Ctrl+R** — сначала, **L** — сменить язык.

## Игра для игрока

Без `--start` и `--editor-port` игра открывается **главным меню**: «Продолжить» (последнее
сохранение), «Новая игра», «Загрузить», «Настройки», «Выход». Найденные концовки — счётчиком.

| Где | Что |
| --- | --- |
| В игре | кнопки «Авто» и «≡» справа сверху; Esc или «Назад» на Android — пауза |
| Пауза | вернуться, сохранить, загрузить, история реплик, настройки, главное меню, выход |
| Сохранения | 4 страницы по 6 слотов со скриншотами + автосохранение (вход в каждый узел, сворачивание на Android, закрытие окна) и быстрое (F5 / F9) |
| Настройки | громкость: общая, музыка, звуки, голос; скорость текста; пауза авто-режима; во весь экран; язык |

Сохранение хранит место (узел и строку), переменные, сцену (фон, персонажи, музыка), время игры
и последние реплики. Если после обновления игры места больше нет — продолжение с ближайшего узла.
Всё лежит отдельно для каждой игры: `user://<id игры>/` (в Windows — `%APPDATA%\Godot\app_userdata\VN Runtime\<id>`).

## Запустить на любом проекте без упаковки

```
Godot_v4.7.2-stable_win64.exe --path runtime -- --project=D:/путь/к/проекту
```

Аргументы после `--`: `--project=`, `--start=<узел>`, `--lang=en`, `--seed=1`,
`--editor-port=`, `--embed`. Картинки и тексты читаются прямо с диска, без импорта.

## Живое превью

```
python tools/live_preview.py
```

Слева дерево сюжета и переменные, справа игра. Сохранил файл проекта — игра перезагрузилась
на той же реплике (около 15 мс). Двойной клик по узлу или команде — перейти туда.
Значения переменных правятся прямо в таблице.

## Протокол редактор ↔ рантайм

JSON-RPC 2.0 по TCP, одна строка — одно сообщение. Редактор — сервер, рантайм подключается
к `--editor-port`.

| Метод | Параметры | Что делает |
| --- | --- | --- |
| `project.reload` | — | перечитать проект, вернуться на ту же команду с теми же переменными |
| `play.goto` | `node`, `command?`, `keep_vars?` | перейти к узлу; с командой — промотать сцену до неё |
| `play.restart` | — | новое прохождение |
| `play.next`, `play.choose` | `index` | клик и выбор — для автотестов |
| `state.get`, `state.set` | `var`, `value` | переменные и посещения |
| `ping`, `app.quit` | — | |

Уведомления рантайма: `hello` (pid, hwnd, версия), `play.position` (node, command),
`play.ended`, `runtime.error`.

Проверка на твоей машине (с окном — уберите `--headless`):

```
python tools/runtime_check.py --godot "C:/Godot/Godot_v4.7.2-stable_win64_console.exe"
```

## Сборка

Обычно — из редактора: **Игра → Собрать игру…** (см. главный README). Редактор делает сборочную
копию рантайма в `<проект>/build/.staging`, кладёт туда игру и вызывает Godot без окна.

Вручную:

```
python tools/pack_game.py [папка проекта]      # проверить и положить проект в runtime/game
```

Дальше в Godot: **Проект → Экспорт**. Пресеты Windows и Android уже настроены
(`export_presets.cfg`): JSON проекта включён в сборку, тесты исключены.

**Windows:** Editor → Manage Export Templates → Download and Install, затем Экспорт →
Windows Desktop → Export Project. Получится `build/windows/OldHouse.exe`.

**Android** (нужно один раз):
1. Установить [Android Studio](https://developer.android.com/studio) — вместе с ней ставятся SDK и JDK.
2. В Godot: Editor → Editor Settings → Export → Android: указать путь к SDK
   (`%LOCALAPPDATA%\Android\Sdk`) и к JDK (`C:\Program Files\Android\Android Studio\jbr`).
3. Шаблоны экспорта — как для Windows.
4. Экспорт → Android → Export Project → `build/android/OldHouse.apk`.
   Godot подпишет APK отладочным ключом — для установки на свой телефон этого хватает.
5. Скопировать APK на телефон и открыть (разрешить установку из неизвестных источников)
   или, с включённой отладкой по USB, нажать в Godot кнопку запуска на устройстве.

## Ограничения этапа 0

- Профиль игрока один («default»); несколько профилей — этап 3.
- Надписи интерфейса есть на русском и английском; свои тексты и оформление меню — этап 6 (темы).
- Составные спрайты, камера, параллакс, режим исследования — этап 4.
